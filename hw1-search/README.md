Overview:
    This project consists of module A, a shuffleable 8-puzzle that can be solved interactively or can be solved
    by a search algorithm of choice (GBFS, A\*, Dijkstra, BFS), and module B, a tic-tac-toe game with 3 modes: Player
    vs Player, AI vs AI, and Player vs AI, with the AIs using an algorithm of choice (minimax, alpha-beta pruning).

How to Run:
    Dependencies: npm
    After unzipping the file, run npm install in the code directory. Once finished, run npm run dev
    in this same directory and paste the localhost link that vite outputs.

Architecture:
    This assignment is implemented in javascript with the react framework along with basic html and css. 
    It is a single page html application.
    Additional packages like heap-js were used for algorithm implementation. All of the source files are in the src
    directory. I have images for tic tac toe X/O and the 8-puzzle 1/2/3/4/5/6/7/8 inside the images directory. 
    In the application, Module A and B are activated by pressing "Module A" or "Module B". Both
    modules can be active at the same time. 

Algorithms Implemented:
    BFS, Dijkstra, A\*, GBFS, Minimax, Alpha-Beta Pruning, Durstenfeld shuffle algorithm
